A breakthrough is rarely a better fit to the data.

More often it is a decision that the data was about something else. This corpus annotates 2,327 scientific prizes by what kind of thing the contribution actually was — whether it reframed something, measured something new, extended reach, or built an instrument. Existing prize datasets count citations. None of them record this.

The headline finding

53% of awarded work is not a change of description at all — 820 of 1,547 events. It delivered facts, or reach, or a working artifact.

A two-way split misses more than half of what gets awarded.

Machine learning frames discovery as fitting versus reframing. Against 1,547 real awarded contributions, that split has nowhere to put the majority of them: no description changed, so there is nothing to grade as shallow or deep.

The annotation scheme  /  axis 2 of 2

Where a description did change, how far did it move?

Six rungs, and they are ordered — that ordering is what carries the argument. Machine learning has an operation for exactly one of them.

L5 Change the repertoire of moves itself Cohen 1966 — forcing 1
L4 Introduce a kind of object the language lacked Scholze 2018 — perfectoid spaces 181
L3 Bridge one domain onto another Bennett & Brassard 2025 — quantum communication 189
L2 Retype, merge or split what counts as the same Cook 1982 — NP-completeness 501
L1 Same predictions, less structure Nambu 2008 — symmetry breaking carried into particle physics 38
L0 Solved inside the existing description Duminil-Copin 2022 — phase transitions in three and four dimensions 131

The shaded rung is everything machine learning does today — 131 of 1,041 depth labels. It is not the shallow end: Duminil-Copin won a Fields Medal there. It is simply the only rung with an operation. And strict reinterpretation — L1, same predictions with less structure, Einstein against Lorentz — is the rarest move in the corpus at 38 events.

Axis 1 of 2

What did the contribution change?

Every event gets exactly one mode. Modes are nominal — no ordering holds between measuring something new and retyping what counts as the same — which is why they are kept on a separate axis from the ladder above.

What you get

One SQLite file, five CSVs, and a script that checks our arithmetic.

Every statistic on this page is recomputed from the shipped data by scripts/summary.py. It exits non-zero if any published number fails to reproduce. Run it before you trust us.

# reproduces all 30 published statistics, straight from the data
python3 scripts/summary.py

# every contribution that introduced a kind of object its language lacked
SELECT a.year, a.laureate, c.levels, c.ops, a.citation
  FROM awards a
  JOIN classifications c
    ON a.prize_key = c.prize_key AND a.year = c.year
 WHERE c.levels LIKE '%L4%'
 ORDER BY a.year DESC;

Read this before using the annotations

One annotator, and it is a language model.

These are not the judgements of human domain experts. Every count on this page is one annotator’s reading of the official citation text, under human direction. There is exactly one annotator, so no inter-annotator agreement statistic exists — and we do not report a proxy for one.

The soft boundary

A paper that reports a measurement often reframes something too, and which half the citation rewards is a judgement call. Read the 53% as a lower bound on how badly a two-way split fails, not as a constant.

The scheme is not symmetric

The facts column draws its own coarse distinction — facts newly in hand versus reach newly extended — but encodes it as two modes rather than as a ladder. A scheme that graded every column would be cleaner. We did not build one.

Hindsight and selection

Prizes are awarded with decades of hindsight, so the corpus samples work that turned out to matter, and citations justify a decision already taken. Physics and mathematics are better represented than biology or the earth sciences.

Confidence is self-reported

Evidence grades — A (1,442), B (77), C (28) — record how directly the citation supported the call. They are a confidence signal from the annotator, not a validation of it.

What would help most

Re-annotate a sample. Disagree with us in public.

We cannot tell from the inside whether this scheme is reproducible or whether it records one system’s habits. Only someone else applying it can settle that. A few hundred events is plenty.

  1. Sample a few hundred events from classifications.csv, spread across prizes and eras.
  2. Read only the citation text. That is all our annotator saw — do not read our labels first.
  3. Assign a mode, and a depth if a description changed.
  4. Send the labels. We will publish the agreement statistic whatever it says, including if it is bad.

Also useful: filling a coverage gap in biology or the earth sciences, fixing a wrong record, or attacking the scheme outright. If you can design a symmetric one that survives contact with 1,547 real citations, it supersedes this one and we will say so.
